# STM32 LED Project

6项任务分别存放在6个文件夹
1.外接LED灯 以 500ms 周期闪烁， 可以使用 HAL_Delay 进行延时;
Task1_HAL_delay_LEDSpark
2.外接LED灯 以 500ms 周期闪烁， 全程不使用 HAL_Delay 和Gettick进行延时;

3.按键通过 EXTI 中断控制 LED 灯开关，要求必须有软件消抖 20ms;

4.注册个人GitHub账号并把代码提交到仓库，交作业时给出仓库链接;
这些任务既可以创建多个Keil项目分别实现，也可以集成到一个项目中，但提交时需要将其放在一个仓库里提交，在README中写明自己做了哪一部分
